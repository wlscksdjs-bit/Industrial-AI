  * **강의 자료**:

### 2. 🌐 [지능형 IoT 네트워크 (Intelligent IoT Network)](./지능형%20IoT%20네트워크/)
* **담당 교수**: 이혁로 교수님
* **주요 내용**: 산업 인공지능 인프라를 뒷받침하는 차세대 센서 네트워크, OSI 7계층 프로토콜, WSN, LPWAN, 산업용 메시징 프로토콜(MQTT, OPC UA) 및 암호화 네트워크 트래픽 다중 분류 딥러닝 모델링.
* **주요 산출물**:
  * **강의 자료**: 1주차(오리엔테이션), 2주차(지능형 IoT 개요), 3주차(지능형 IoT와 OSI 7계층), 4주차(무선 통신 기술), 5주차(데이터 수집 및 MQTT), 6주차(OPC UA 개요) PDF
  * **[3주차 연구 과제: 트래픽 분류 모델 성능 향상 (`3주_과제/`)](./지능형%20IoT%20네트워크/3주_과제/)**:
    * **연구 주제**: ISCXVPN2016 암호화 트래픽 다중 분류(5개 클래스)에서 머신러닝 기준 모델(Random Forest, 76.44%)을 상회하는 딥러닝 아키텍처 구축.
    * **핵심 방법론**: 30개 도메인 피처 + 계층적 트리 로짓 융합(40차원) + ResBlock + 5-Seed 앙상블 **TDF-Net** 설계.
    * **검증 성과**: **정확도 78.61%** (RF 대비 +2.16%p 상회), **Macro F1 0.7402** (RF 대비 +0.0432 상회) 달성.
  * **[5주차 실무 과제: MQTT 기반 실시간 설비 이상 탐지 (`5주_과제/`)](./지능형%20IoT%20네트워크/5주_과제/)**:
    * **연구 주제**: 스마트 공장 가상 센서 스트리밍, MQTT 브로커 연동, 실시간 이상치 탐지 및 경보 시스템 구현.
    * **주요 구성**: `sensor_simulator.py`(발행기), `alarm_service.py`(탐지/경보 서비스), `watch_alarms.py`(관제 모니터), `check_alarms.py`(정확도 검증기), 결과보고서(PPTX/HTML).
  * **[6주차 실습 과제: OPC UA 정보 모델 실습 (`6주_과제/`)](./지능형%20IoT%20네트워크/6주_과제/)**:
    * **연구 주제**: 산업용 표준 OPC UA 서버/클라이언트 연동, Address Space 노드 탐색 및 데이터 교환.

### 3. 🚀 [어프렌티스 프로젝트 (Apprentice Project)](./어프렌티스%20프로젝트/)
* **담당 교수**: 이석구 교수님
* **주요 내용**: 산업 현장 도메인 데이터 기반 머신러닝 전주기 5대 핵심 절차(문제정의, 분할, 스케일링, 튜닝, 평가) 실증 및 시계열(Time-Series) 딥러닝(RNN, LSTM, GRU) 기반 예측 프로젝트.
* **주요 산출물**:
  * **강의 자료**: 2주차(데이터 분할, 스케일링, 논문 종류), 5주차(RNN, LSTM, GRU 시계열 딥러닝) PDF
  * **[프로젝트 1: 제조 가공 설비 고장 예측 머신러닝 5단계 실증](./어프렌티스%20프로젝트/)**:
    * **연구 주제**: AI4I 2020 공작기계 1만 건 센서 로그 기반 가공 중 설비 고장 사전 감지 이진 분류 (희소 고장률 3.4%).
    * **검증 성과**: 고장 재현율(Recall) **86.8%** (+36.8%p 향상), F1-Score **0.868**, ROC-AUC **0.986** 달성.
    * **주요 산출물**: 6장 요약 발표자료(PPTX), 5분 발표 구두 대본(PDF/DOCX), Q&A 대비 대본, `run_project1_experiment.py`.
  * **[프로젝트 2: ETTh1 다변량 시계열 기반 전력 변압기 유온 1시간 후 예측 (`2차 PJT/`)](./어프렌티스%20프로젝트/2차%20PJT/)**:
    * **연구 주제**: ETTh1 17,420개 시간별 센서 데이터를 바탕으로 6개 부하 변수를 통해 1시간 후 오일 온도(OT)를 예측하는 시계열 회귀 모델링.
    * **핵심 방법론**: 시계열 시간순 분할, Lag/Rolling 피처 엔지니어링, 다중 모델(Linear, Ridge, MLP, GRU, LSTM) 비교 평가.
    * **주요 산출물**: 16:9 인터랙티브 슬라이드 덱(HTML v3), 5분 발표 구두 대본(DOCX/MD), `run_project2_upgrade_experiment.py`, 정량 평가 차트 일체.
