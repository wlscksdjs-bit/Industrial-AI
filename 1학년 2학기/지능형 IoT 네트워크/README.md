# 🌐 지능형 IoT 네트워크 (Intelligent IoT Network)

본 폴더는 충북대학교 일반대학원 산업인공지능학과 1학년 2학기 **지능형 IoT 네트워크** 강의의 강의 자료 및 관련 과제/실습 산출물을 아카이빙하는 공간입니다.

---

## 📌 교과 개요 및 목표
* **교과목명**: 지능형 IoT 네트워크 (Intelligent IoT Network)
* **주요 내용**: 산업용 IoT(IIoT) 환경 및 엣지-클라우드 연계 네트워크 구조, 무선/유선 센서 네트워크 프로토콜, 지능형 네트워크 제어 및 데이터 전송 최적화 기법을 다룹니다.
