# 🎙️ [지능형 IoT 네트워크] 주차별 정규 강의록 아카이브

> **담당 교수**: `김한진 교수님`  
> **교과목 개요**: 스마트 제조를 위한 컴퓨터 네트워크, OSI 7계층, MQTT 발행/구독, OPC UA 주소공간 모델링, InfluxDB 시계열 연계 및 자율 안전 인터록
