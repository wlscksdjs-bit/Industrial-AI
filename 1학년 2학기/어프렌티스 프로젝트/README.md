# 🚀 어프렌티스 프로젝트 (Apprentice Project)

## 🏭 실증 프로젝트 1: 제조 가공 설비 고장 예측 머신러닝 5단계 실증

### 1. 프로젝트 배경 및 문제 정의
* **대상 데이터셋**: UCI / Kaggle 공개 AI4I 2020 Predictive Maintenance Dataset (10,000건 센서 로그)
* **목표 문제**: 밀링 공작기계 가공 중 설비 고장(Machine Failure) 발생 여부를 사전에 감지하는 이진 분류(Binary Classification)
* **데이터 특성 및 극복 과제**:
  * **극단적 클래스 불균형**: 전체 10,000건 중 정상 9,661건, 고장 339건 (고장률 단 **3.4%**의 희소 이벤트)
  * **센서별 수치 범위 편차 및 이상치**: 공구 모터 급기동 시 발생하는 일시적 토크 스파이크(최대 76.6 Nm)로 인한 왜곡
  * **도메인 파생 특성 구축**: 설비 방열 지표(온도차 $\Delta T$), 기계적 출력 동력($P = \tau \cdot \omega$), 공구 피로도 복합 피처 추가

---

### 2. 머신러닝 전주기 5대 핵심 절차 실증

```
[1단계: 문제 정의 및 도메인 피처 엔지니어링]
  - 10,000건 센서 로그, 희소 고장률 3.4%
  - 물리 도메인 파생 특성(방열, 회전 동력, 공구 마모) 구축
       │
       ▼
[2단계: 데이터 분할 및 검증셋(Validation Set) 분리]
  - Train(60%) : Val(20%) : Test(20%) 3단계 계층적 층화 분할(Stratified Split)
  - 검증셋을 통한 독립 튜닝 보장 및 시험 데이터(2,000건) 최종 평가 전 완전 밀봉
       │
       ▼
[3단계: 데이터 스케일링 및 데이터 누수(Data Leakage) 원천 차단]
  - 토크 스파이크 이상치 왜곡 방지를 위한 RobustScaler(중앙값 및 IQR 기반) 채택
  - Fit 기준값은 오직 학습셋(60%)에서만 산출하여 검증·시험셋 누수 완벽 차단
       │
       ▼
[4단계: 모델 규제 및 하이퍼파라미터/임계값 튜닝]
  - Random Forest 트리 깊이를 10으로 제한하여 과적합 격차 38% -> 9.3%로 안정화
  - 희소 고장 미검출(False Negative) 방지를 위해 분류 결정 임계값을 0.35로 최적화
       │
       ▼
[5단계: 최종 시험셋 단 1회 평가 및 실전 성능 검증]
  - 고장 검출 재현율(Recall): 86.8% (고장 68건 중 59건 적시 검출)
  - F1-Score: 0.868 | ROC-AUC: 0.986 달성
```

| :--- | :---: | :---: | :---: |
