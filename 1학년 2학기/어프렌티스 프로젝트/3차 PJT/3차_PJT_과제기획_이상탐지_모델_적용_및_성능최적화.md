## 1. 프로젝트 추진 배경 및 학사 일정 공지 반영

### 1.1 프로젝트 추진 배경
- 현대 산업 제조 및 플랜트 설비는 가동 중단(Downtime) 시 막대한 경제적 손실과 안전 사고를 유발하므로, 센서 데이터를 실시간으로 모니터링하여 설비 고장 및 비정상 동작을 조기에 진단하는 **이상탐지(Anomaly Detection) 및 예지보전(PdM)** 기술이 필수적임.
- 1차 프로젝트(제조 설비 고장 예측 머신러닝 5단계 실증)와 2차 프로젝트(ETTm1/ETTh1 다변량 시계열 유온 Forecasting)를 통해 다변량 데이터 전처리, 데이터 누수 방지 스케일링, 시계열 동역학 모델링 역량을 축적함.
- 이번 3차 프로젝트에서는 정상 데이터 중심의 **비지도/원클래스(Unsupervised/One-Class) 학습 패러다임**을 바탕으로, 서로 다른 메커니즘을 가진 **이종 이상탐지 알고리즘 2종 이상을 직접 설계·구현하고 비교**하여 최적의 탐지 성능을 도출하고자 함.

### 3.1 대상 데이터셋: SKAB (Skoltech Anomaly Benchmark)
- **도메인**: 스콜텍(Skoltech) 연구소의 산업 워터 루프(Water Loop) 수처리/순환 시스템 테스트베드.
- **수집 장비**: 원심 펌프, 조절 밸브, 배관 루프, 물 저장 탱크, 인버터 등으로 구성된 실제 산업 공정 축소 설비.
- **주요 센서 변수 (8개 특성)**:
  1. `Accelerometer1RMS`, `Accelerometer2RMS`: 모터 및 펌프의 기계적 진동 가속도 (실효값, RMS)
  2. `Temperature`: 배관 및 순환 유체 온도 센서
  3. `Pressure`: 배관 내부 압력 센서
  4. `Flowmeter`: 유체 유량 측정 센서
  5. 기타 전력/전류 센서 및 인버터 구동 주파수 신호
- **이상 유형(Fault Types)**: 밸브 폐쇄/열림 오류, 펌프 캐비테이션, 배관 누수, 센서 오작동 등 30개 이상의 시나리오별 결함 데이터셋 제공.
- **라벨 구성**: `anomaly` (0: 정상, 1: 이상) 및 결함 원인 태그 명시.

### 3.2 탐색적 데이터 분석(EDA) 계획
1. **정상 시계열 패턴 분석**: 
   - 펌프 기동 및 정상 순환 시 센서별 주기성(Periodicity) 및 베이스라인 신호 범위 확인.
   - 센서 간 상관계수(Heatmap) 및 시차 상관관계(Cross-Correlation) 분석으로 연동 센서(압력-유량, 진동-온도) 식별.
2. **이상 발생 구간 신호 왜곡 분석**:
   - 이상 징후 발생 시 선행 지표(가속도 진동 급변)와 후행 지표(압력 강하, 온도 상승) 간의 시간차(Lag) 규명.
   - 정상 구간 대비 이상 구간의 평균, 분산, 왜도, 첨도의 통계적 편차 분석.

### 3.3 전처리 및 특징 엔지니어링 파이프라인
1. **데이터 누수 방지 스케일링**:
   - 극단치(Spike)에 강건한 `RobustScaler` 사용 (중앙값 및 사분위간 범위 IQR 기준).
   - **스케일러 기준치는 오직 정상 학습 데이터에서만 `fit`하고, 검증 및 시험 세트에는 `transform`만 적용**.
2. **시계열 슬라이딩 윈도우(Sliding Window) 생성**:
   - 과거 $W$개 시점($W \in \{10, 30, 60\}$)의 센서 신호를 묶어 3차원 텐서 `(Batch, Window_Size, Features)` 형태로 변환.
3. **물리 파생 변수 추가 (2차 PJT 교수님 피드백 반영)**:
   - 가속도 합성 벡터 크기: $A_{mag} = \sqrt{Acc1^2 + Acc2^2}$
   - 센서 신호의 1차 차분(변화량, $\Delta$): 급격한 압력 변동 및 유량 스파이크 감지용.

## 4. [2단계] 이상탐지 모델 설계 및 구현 전략

### 4.1 학습 패러다임: 엄격한 비지도/원클래스 학습
- **학습 데이터**: 이상 라벨이 전혀 없는 **100% 정상 데이터(Label 0)** 만으로 모델 훈련.
- **검증/평가 데이터**: 정상 상태와 다양한 고장 시나리오가 포함된 데이터셋에서 탐지율 평가.

### 4.2 모델 A (머신러닝): Isolation Forest (트리 기반 고립 기법)
- **접근 방식**: 모델 기반 (Model-based / Density-partitioning)
- **수학적 메커니즘**:
  - 정상 데이터는 다변량 공간에 밀집되어 있어 고립시키기 위해 많은 수의 트리 분할(깊은 깊이 $h(x)$)이 필요함.
  - 반면 이상치는 밀도가 희박하고 정상 군집에서 벗어나 있어 적은 횟수의 무작위 분할(짧은 깊이 $h(x)$)만으로 쉽게 고립됨.
  - 이상 점수 산출식:
    $$s(x, n) = 2^{-\frac{E(h(x))}{c(n)}}$$
    ($E(h(x))$: 경로 길이의 기댓값, $c(n)$: $n$개 샘플 트리의 평균 경로 길이)
    점수 $s(x, n) \to 1$일수록 이상치 확률이 높음.
- **장단점**: 
  - [장점] 훈련 및 추론 속도가 매우 빠르고, 고차원 데이터에서도 과적합 위험이 적으며 해석이 직관적임.
  - [단점] 시계열 센서 데이터의 시간적 전후 종속성(Temporal Dependency)을 직접 학습하지 못하므로 윈도우 집계치에 의존해야 함.

### 4.3 모델 B (딥러닝): LSTM-AutoEncoder (시계열 재구성 오차 기반)
- **접근 방식**: 재구성 오차 기반 (Reconstruction Error-based)
- **수학적 메커니즘**:
  - 인코더 LSTM이 정상 센서 신호의 다변량 시퀀스 $X = \{x_1, x_2, \dots, x_W\}$를 저차원 잠재 표현(Latent Vector $Z$)으로 압축.
  - 디코더 LSTM이 $Z$로부터 원래의 시퀀스를 복원 $\hat{X} = \{\hat{x}_1, \dots, \hat{x}_W\}$.
  - 정상 데이터의 시간적 동역학만 학습했기 때문에, 이상 패턴이 들어오면 복원 능력이 상실되어 재구성 오차(Reconstruction Error)가 급증함.
  - 시점 $t$에서의 이상 점수(Anomaly Score):
    $$\text{Score}(t) = \frac{1}{D} \sum_{d=1}^D (x_{t,d} - \hat{x}_{t,d})^2$$
- **네트워크 구조 설계**:
  - `Encoder`: LSTM(64) -> Dropout(0.2) -> LSTM(32)
  - `Bottleneck`: Latent Vector (32차원)
  - `Decoder`: RepeatVector -> LSTM(32) -> LSTM(64) -> TimeDistributed(Dense(Features))
- **장단점**:
  - [장점] 복잡한 센서 간의 비선형 상관관계와 시간적 연속성을 정밀하게 포착하여 미세한 이상 징후도 탐지 가능.
  - [단점] 신경망 학습 시간이 길고, 하이퍼파라미터(잠재 차원, 레이어 수 등)에 민감함.

### 4.4 이종 모델 비교 요약

| 비교 항목 | 모델 A: Isolation Forest | 모델 B: LSTM-AutoEncoder |
| :--- | :--- | :--- |
| **알고리즘 계열** | 비모수 머신러닝 (Ensemble Tree) | 딥러닝 순환신경망 (RNN/LSTM) |
| **이상 판별 기준** | 고립 트리 평균 경로 길이 (Path Length) | 원본 시퀀스 복원 오차 (MSE Loss) |
| **시간 종속성 반영** | 윈도우 통계량 평탄화(Flatten)로 간접 반영 | LSTM 순차 메모리 셀을 통해 직접 반영 |
| **학습/추론 연산량** | 초경량 (CPU 환경에서 수초 내 훈련 완료) | 중량 (GPU 가속 권장, 역전파 연산 필요) |
| **현업 적합성** | 엣지 디바이스/경량 게이트웨이 적합 | 고성능 서버 기반 정밀 진단 시스템 적합 |

## 5. [3단계] 성능 평가 지표 및 최적화(Ablation) 실험 설계

### 5.1 성능 평가지표 체계 (교수님 필수 3대 지표 + 불균형 지표)
1. **$F_1$-Score (조화 평균, 필수)**:
   $$F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$
2. **Precision (정밀도, 필수)**: 모델이 이상이라고 판정한 것 중 실제 이상인 비율 (오탐 False Positive 방지력).
3. **Recall (재현율, 필수)**: 실제 이상 중 모델이 놓치지 않고 감지한 비율 (설비 예지보전에서 미탐 False Negative 방지가 핵심).
4. **AUPRC (Area Under Precision-Recall Curve, 권장 핵심 지표)**:
   - 산업 센서 데이터는 이상 비율이 극히 낮은(1~5%) 불균형 데이터셋임.
   - ROC-AUC는 거대한 정상 음성(True Negative)으로 인해 점수가 과대평가되는 왜곡이 발생하므로, 소타(SOTA) 이상탐지 논문 표준인 **AUPRC를 채택하여 모델을 객관적으로 평가**.

### 5.2 Point Adjustment (PA) 무결성 검증 (교수님 강의 특별 지침)
- **PA 편향 문제**: 연속된 이상 구간 중 단 1개의 타임스탬프만 맞춰도 전체 구간을 모두 맞춘 것으로 판정하는 관행으로 인해 성능이 비정상적으로 부풀려지는 현상 발생.
- **검증 대책**:
  - **Without PA (순수 Point-wise 평가)**: 보정 없이 매 시점별 탐지 성능 산출 (실제 실시간 진단 성능).
  - **With PA (구간 보정 평가)**: 전통적 벤치마크 비교용으로 병행 표기.
  - 두 결과를 나란히 비교하여 모델의 실제 탐지 신뢰도를 투명하게 입증함.

### 5.3 임계값(Threshold, $\tau$) 최적화 전략
- 재구성 오차 및 고립 점수를 이진 분류(0 or 1)로 변환하기 위한 임계값 $\tau$ 결정:
  1. **통계적 기준선**: 정상 검증 데이터셋의 점수 분포에서 $\mu + 3\sigma$ 또는 상위 99 백분위수($P_{99}$) 적용.
  2. **$F_1$ 극대화 탐색 (Threshold Sweeping)**: 검증셋에서 임계값을 100단계로 스캔하여 $F_1$-Score가 최대가 되는 최적의 $\tau^*$ 도출.
  3. Precision-Recall Curve 상에서 최적의 작동 지점(Operating Point) 선정.

### 5.4 성능 개선 및 어블레이션(Ablation) 실험 설계
- **실험 1: 윈도우 크기($W$) 탐색 실험**:
  - $W \in \{10, 30, 60\}$ 비교 (단기 스파이크성 고장 vs 장기 추세성 열화 탐지력 비교).
- **실험 2: 특징 세트(Feature Set) 효과 검증**:
  - `Base`: 8개 원본 센서
  - `Base + Diff`: 원본 센서 + 1차 차분(변화량) 변수
  - `Base + Diff + Magnitude`: 가속도 합성 벡터 파생 변수 추가
- **실험 3: 모델 아키텍처 및 손실 함수 최적화**:
  - LSTM-AE 잠재 차원($Z \in \{16, 32, 64\}$)에 따른 정보 압축률과 복원력 트레이드오프 분석.
  - MSE Loss vs Huber Loss (이상치 노이즈에 대한 강건성 비교).

## 6. [4단계] 결과 분석 및 사후 진단 전략

### 6.1 센서별 이상 기여도 분석 (Root Cause Attribution)
- 다변량 이상 탐지에서 단순히 "이상이 발생했다"를 넘어 **"어떤 센서/부품이 이상을 유발했는가?"** 를 진단하는 것이 필수적임.
- 다변량 오차 벡터를 각 센서 $d$별로 분해:
  $$\text{Contribution}_d(t) = \frac{(x_{t,d} - \hat{x}_{t,d})^2}{\sum_{k=1}^D (x_{t,k} - \hat{x}_{t,k})^2}$$
- 이상 발생 시점의 기여도 상위 센서를 추출하여 시각화 차트(Bar/Heatmap)로 제시.

### 6.2 오탐(FP) 및 미탐(FN) 오류 케이스 스터디
- **오탐 분석**: 설비 기동 시점이나 정상적인 제어 명령(인버터 주파수 변동)에 의한 일시적 과도 상태를 이상으로 오인한 사례 분석.
- **미탐 분석**: 매우 서서히 진행되는 마모/온도 상승으로 인해 재구성 오차가 임계값을 넘지 못한 사례 분석 및 개선안 제안.
