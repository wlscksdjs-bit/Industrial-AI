## 🎯 1. 강의 핵심 개요 (Executive Overview)

* [1. 프로젝트 일정 및 평가 방식 변경] 교수님은 기존 5차 프로젝트 계획을 3차 프로젝트 및 최종 프로젝트로 1회 축소하고, 최종 발표를 12월 10일과 17일 이틀간 대면으로 진행하며 평가 방식을 발표와 자료 검토로 이원화하여 진행함을 공지함.
* [2. 학생 프로젝트 발표 및 피드백] 유경득, 고병렬, 박준영, 성우철 학생이 변압기 오일 온도 예측 프로젝트 결과를 발표함. 각 발표자는 데이터셋, 모델 비교(RNN, LSTM, GRU), 하이퍼파라미터 튜닝, 어블레이션 테스트 결과 및 질의응답을 공유함. 교수님은 각 발표 내용에 대한 구체적인 피드백과 함께 데이터 분석의 중요성, 시계열 예측 용어의 정확한 사용, 변화량 예측의 유효성 등에 대해 강조함.
* [3. 이상 탐지(Anomaly Detection) 이론 강의 및 3차 프로젝트 안내] 교수님은 이상 탐지의 개념, 아웃라이어/노벨티와의 차이, 다양한 적용 분야 및 알고리즘 유형(밀도 기반, 모델 기반, 재구성 오차 기반, 생성적 적대 신경망 기반)을 설명함. 또한 이상 탐지 모델의 학습 방식(정상 데이터만 활용)과 성능 지표(F1, Precision, Recall 등)를 소개하고, 3차 프로젝트 과제로 이상 탐지 모델 설계 및 비교를 제시함.

## 📑 2. 세부 챕터 및 타임라인 요약 (Timeline & Topics)

### 🕒 [00:00] 프로젝트 일정 및 평가 방식 변경 공지
* **발표/진행**: `채민선 교수님`
* **핵심 내용**: 교수님은 기존 5차 프로젝트 계획을 3차 및 최종 프로젝트로 1회 축소하고, 최종 발표를 12월 10일과 17일 이틀간 대면으로 진행함을 공지함. 평가 방식은 발표와 자료 검토를 병행하며, 학생 상호 평가와 교수님 점수를 합산하여 최종 성적을 산정할 예정임을 설명함. 또한, 마지막 프로젝트의 주제 제약(타임 시리즈)을 완화하여 일반 데이터 분류/예측도 가능하게 변경함.
* **주요 포인트**:
  - 프로젝트 횟수 1회 축소 (5차 -> 3차 및 최종)
  - 최종 발표 12월 10일, 12월 17일 대면 진행
  - 평가 방식: 11분 발표, 11분 자료 검토 (크로스 평가)
  - 최종 성적: 학생 상호 평가 + 교수님 점수 합산
  - 마지막 프로젝트 주제: 타임 시리즈 제약 삭제, 일반 데이터 분류/예측 가능

### 🕒 [00:10] 유경득 학생 프로젝트 발표: 변압기 오일 온도 예측 (ETT 데이터 TTH1)
* **발표/진행**: `화자 3`
* **핵심 내용**: 유경득 학생은 변압기 데이터 TTH1을 사용하여 과거 96시간을 보고 다음 24시간을 예측하는 문제를 다룸. RNN, LSTM, GRU 세 모델을 동일 조건(히든 64, 레이어 2층, 러닝 레이트 0.001)에서 시드 3개로 반복 실험하여 평균 오차를 비교함. 검증 결과 MAE가 1.7도로 가장 낮고 시드 3개 모두 1등인 RNN 모델을 채택함. 학습 곡선에서 검증 오차가 출렁이는 이유를 학습 데이터와 검증/테스트 데이터 간 온도 변화 폭 차이로 분석함. 어블레이션 테스트를 통해 히든 사이즈 32~64, 레이어 4층, 입력 길이 96시간이 적절함을 확인했으나, 단순 마지막 값 반복 예측(Naive) 모델과 오차가 비슷하고 R2는 Naive가 더 좋았음을 밝힘. 이는 테스트 기간의 낮은 온도 변화 때문으로 판단함.

### 🕒 [00:20] 고병렬 학생 프로젝트 발표: 변압기 오일 온도 사전 예측 (ETT 데이터 M2)
* **발표/진행**: `화자 3`
* **핵심 내용**: 고병렬 학생은 ETT 데이터셋 M2(15분 간격 변압기 데이터)를 활용하여 변압기 오일 온도 사전 예측을 주제로 발표함. 과거 24시간의 부하와 온도를 기반으로 4시간까지의 오일 온도를 예측하는 목표를 설정함. RNN, LSTM, GRU 세 모델을 동일 조건에서 3회 반복 실험한 결과, GRU가 MAE/MSE에서 가장 낮은 오차를 보였고, LSTM, RNN 순이었음을 보고함. 어블레이션 테스트에서는 입력 길이를 12, 24, 48시간으로 변경하여 24시간에서 오차가 가장 낮음을 확인, 데이터의 하루 주기에 맞는 입력 길이가 최적임을 제시함. 최종 평가에서 GRU는 RNN보다 MSE를 33% 줄였고, 4시간 뒤 오일 온도를 평균 1.47도 오차로 예측함. 온도가 급격히 오르는 구간에서 예측이 늦게 따라가는 한계를 지적하며, 향후 고온 구간 경보 성능 검증 필요성을 언급함.

### 🕒 [00:27] 박준영 학생 프로젝트 발표: ETT M1 오일 온도 예측
* **발표/진행**: `화자 3`
* **핵심 내용**: 박준영 학생은 ETT M1 데이터를 사용하여 오일 온도(OT) 예측 프로젝트를 발표함. OT 변수는 스탠다드 스케일러를 적용 후 예측을 진행함. 콜랩 환경에서 7개 변수를 입력으로 미래 1시간을 예측하는 문제로 정의하고, 데이터는 60:20:20으로 분할함. 공통 설정으로 히든 사이즈 64, 레이어 2개, 드롭아웃 적용, 학습률 0.001, 에포크 30회(조기 종료)를 사용함. 초기 성능 테스트에서 GRU가 가장 좋은 결과를 보임. 어블레이션 테스트에서는 입력 길이를 12, 24, 48시간으로 변경하여 실험한 결과, 48시간 기준 GRU가 가장 좋았으나, 입력 길이가 길어진다고 항상 성능이 좋아지는 것은 아님을 확인함. 최종 성능 평가에서 GRU는 룩백 48시간일 때 RMSE가 가장 좋았고, Naive 모델 대비 0.26% 개선을 보였으나, 단일 시드 실험으로 반복 확산 추가 검증이 필요함을 언급함.

### 🕒 [00:32] 성우철 학생 프로젝트 발표: 전력 변압기 데이터 OIL 온도 예측 (ETT M2)
* **발표/진행**: `화자 3`
* **핵심 내용**: 성우철 학생은 ETT M2 데이터를 활용하여 전력 변압기 오일 온도(OT) 예측을 수행함. OT와 연관된 HULL, MUFL, MULL 변수 중 MUFL의 잘못된 데이터를 삭제하고 HULL, MULL을 입력 변수로 사용함. 데이터는 1년치를 학습, 6개월치를 검증, 나머지 6개월을 테스트 데이터로 분할함. PyTorch를 이용해 RNN, LSTM, GRU 모델을 사용하고, 손실 함수는 MSE, 최적화기는 Adam을 사용함. 기본 결과에서 GRU가 밸리데이션 MSE가 안정적으로 유지되며 가장 높은 성능을 보임. 어블레이션 테스트에서 입력 길이를 0.5일, 1일, 7일, 14일로 변경한 결과, RNN은 입력 길이가 길수록 성능이 저하되었고, LSTM/GRU는 14일치 입력에서 가장 좋은 결과를 보였으며 GRU가 더 우수했음을 보고함. 그러나 전반적으로 데이터 자체의 한계(상온 부재)로 인해 실질적으로 쓸 수 있을 정도의 데이터는 아니라고 판단함. OT만으로 예측 시 매우 높은 정확도가 나오므로, HULL과 MULL만으로 예측한 결과는 기적에 가깝다고 평가함.

### 🕒 [00:45] 교수님 피드백 및 시계열 데이터 분석 강조
* **발표/진행**: `채민선 교수님`
* **핵심 내용**: 교수님은 학생들의 발표 내용에 대해 전반적으로 많은 고민과 노력이 엿보였음을 칭찬함. 특히 시계열 데이터 분석 시 'Forecasting'과 'Prediction' 용어의 정확한 사용을 강조하며, Forecasting이 시간에 대한 예측을 포함하는 개념임을 설명함. 또한 데이터 분석의 중요성을 강조하며, 데이터의 성격 파악(흐름, 주기), 히트맵을 통한 변수 간 관계 분석, 시차 상관관계 분석을 통한 주기성 파악이 선행되어야 함을 지적함. 예측 방식에 있어 절대값 예측 외에 변화량 예측의 유효성을 언급하고, 다변량 분석 모델에서도 단변량 분석을 시도한 학생들의 고민을 긍정적으로 평가함. 마지막으로 어블레이션 테스트의 정확한 개념(제안한 모듈의 기능 제거)을 하이퍼파라미터 튜닝과 구분하여 설명함.
* **주요 포인트**:
  - 시계열 데이터 예측 시 'Forecasting' 용어 사용 권장
  - 데이터 분석 시 데이터의 성격 파악, 주기성 확인, 시차 상관관계 분석 선행 강조
  - 어블레이션 테스트는 제안한 방법/모듈의 기능을 하나씩 제거하며 비교하는 실험임을 명확히 함 (하이퍼파라미터 튜닝과 구분)

### 🕒 [01:00] 이상 탐지(Anomaly Detection) 이론 강의
* **발표/진행**: `채민선 교수님`
* **핵심 내용**: 교수님은 이상 탐지(Anomaly Detection, 애너멀리 디텍션)에 대한 강의를 진행함. 이상 탐지는 시계열 데이터뿐만 아니라 다양한 분야(반도체 제조, 예지보전, 자율주행, 보안, 언어 분석 등)에 적용될 수 있음을 설명함. 이상 탐지의 개념을 아웃라이어(Outlier) 및 노벨티(Novelty)와 구분하여 설명하며, 현재는 '애너멀리'로 용어가 정립되었음을 강조함. 이상 탐지 알고리즘은 밀도 기반, 모델 기반, 재구성 오차 기반, 생성적 적대 신경망 기반의 네 가지 유형으로 분류되며, 이는 통계-머신러닝-딥러닝의 발전 흐름과 일치함을 설명함. 이상 탐지는 정상 데이터만으로 학습하는 '원클래스 분류(One-Class Classification)' 또는 '비지도 학습'의 특성을 가지며, 클래스 불균형이 심한 데이터에 적합함을 강조함. 성능 지표로는 F1 스코어, Precision, Recall 외에 AUPRC, ROCAUC, 시계열 구간 이벤트 연속성 지표 등을 소개함. 마지막으로 이상 탐지 모델은 정상 데이터만으로 학습하고, 평가용 데이터에는 라벨이 있어야 함을 강조하며, 실제 현업에서는 정상 데이터 정리의 어려움과 이상 발생 시 원인 변수 분석의 필요성이 주요 이슈임을 언급함.
* **주요 포인트**:
  - 3차 프로젝트에서 이상 탐지 모델 설계 및 비교를 수행해야 함.

## 💡 3. 교수님 핵심 강조 및 과제/평가 공지 (Key Directives)

- ★ [교수님 공지] 프로젝트 횟수를 5차에서 3차 및 최종 프로젝트로 1회 축소함.
- ★ [교수님 공지] 최종 발표는 12월 10일과 12월 17일 이틀간 대면으로 진행함.
- ★ [교수님 공지] 최종 평가 시 11분은 발표를 대면으로 진행하고, 나머지 11분은 자료로만 평가하는 방식으로 진행함.
- ★ [교수님 공지] 최종 평가 점수는 학생 상호 평가 점수와 교수님 점수를 합산하여 산정함.
- ★ [교수님 공지] 세부 일정은 공지사항에 게시할 예정임.
- ★ [교수님 공지] 마지막 프로젝트(3차)는 '타임 시리즈'라는 제약된 범위를 삭제하고 일반적인 데이터에 대한 분류나 예측 문제로 진행 가능함.
- ★ [교수님 지시] 3차 프로젝트 데이터셋은 시계열 데이터(GitHub 링크 제공) 또는 다른 데이터셋을 선택하여 사용 가능함.
- ★ [교수님 지시] 3차 프로젝트에서는 최소 2개 이상의 이상 탐지 모델을 비교하여 장점을 분석해야 함.
- ★ [교수님 지시] 3차 프로젝트 성능 지표로 F1 스코어, Precision, Recall은 필수로 제시해야 함.
- ★ [교수님 지시] 3차 프로젝트 모델 학습에 라벨 사용 여부(지도/비지도 학습)를 명확히 제시해야 함.
