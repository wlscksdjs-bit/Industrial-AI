🏆 StandardScaler (Z-Score) z = (x - μ) / σ
센서별 분산을 1.0으로 통일하여 경사하강법 손실 곡면을 등방성 원형으로 교정. 파라미터 진동을 억제하고 최고속 수렴 보장.
❌ MinMaxScaler z = (x - min) / (max - min)
전력 부하 급증 스파이크 이상치(Outlier)에 극도로 취약하여, 정상 운전 구간이 0 부근으로 좁게 압축 왜곡됨.
❌ RobustScaler z = (x - Q2) / IQR
중앙값 기반으로 이상치에 강건하나, 출력 분산이 정규화되지 않아 신경망 비선형 활성화 함수 최적화에 비효율.

Vanilla RNN
게이트: 0개
파라미터: 17,089 학습: 3.76s 상태: 단일 h_t
은닉 상태 갱신 및 출력 수식:
h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b_h)
ŷ_t = W_hy · h_t + b_y (단일 벡터 선형 투영)
BPTT 역전파 체인룰 그래디언트 소실:
∂h_t / ∂h_k = ∏_{j=k+1}^t [diag(1 - h_j²) W_hh^T]
|tanh'| ≤ 1.0 연쇄 거듭제곱으로 인해 t-k > 20 시 그래디언트가 0으로 급속 소멸하여 과거 학습 불가.
단일 은닉 벡터의 구조적 한계:
독립된 기억 셀(Cell State) 없이 단일 h_t에 장기 맥락과 단기 입력이 강제 압축 혼재되어, 24시간 이전 부하 정보가 덮어쓰여 망각됨.
공학적 진단 장기의존성 한계 및 단기 편향
단기(L=12h)에서는 빠르게 적합하나, 시퀀스 증가 시 과거 정보를 망각하여 오차 25.0% 급증 붕괴.
산업 현장 배포 적합성: ❌ 부적합 (장기 신뢰도 결여)
⚠️ 장기의존성 붕괴 (장기 시계열 배포 불가)
LSTM
게이트: 3개
파라미터: 67,201 학습: 3.53s 상태: 이중 (C_t, h_t)
가산적 셀 고속도로 수식:
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t
h_t = o_t ⊙ tanh(C_t) (망각·입력·출력 3게이트 독립 제어)
선형 가산 Cell State 고속도로:
∂C_t / ∂C_{t-1} = f_t (행렬곱 없는 상수 흐름)
f_t ≈ 1.0 유지 시 그래디언트가 감쇠 없이 48스텝 이전으로 직통 전달되어 장기 기억 보존.
3개 게이트 독립 연산 비용:
완벽한 기억 보존을 달성하나, 4개 내부 선형 변환으로 파라미터가 67,201개(최대)로 증가하여 연산량 부담.
공학적 진단 장기 기억 보존 탁월 / 연산 비용
윈도우가 4배(12h→48h) 늘어나도 MAE 0.44~0.45대를 안정 유지하나, 파라미터가 6.7만 개로 가장 큼.
산업 현장 배포 적합성: 🛡️ 보통 (안정적이나 연산량 높음)
🛡️ 장기 기억 완벽 방어 (안정적 방어 모델)
GRU (Gated Recurrent)
게이트: 2개
파라미터: 50,689 (-25%) 학습: 3.33s (최고속) 상태: 통합 h_t
망각+입력 통합 갱신 수식:
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t
z_t: 업데이트 게이트(볼록 결합), r_t: 리셋 게이트
연산량 경량화 & 최고 효율:
파라미터 24.6% 절감 (vs LSTM)
별도의 Cell State 없이 단일 은닉 상태로 통합하여 메모리 점유율 최소화 및 최고속(3.33s).
48h 일주기 부하 최적 압축:
24시간 주야간 전력 변동 2주기를 가장 효율적으로 인코딩하여 전체 1위(MSE 0.4084) 달성.
공학적 진단 최고 연산 효율 및 48h 최우수
48시간 관측 시 일주기 패턴을 가장 완벽히 압축하여 전체 1위(MSE 0.4084) 달성. 현장 엣지 MCU 최적.

1. Vanilla RNN: 기울기 소실로 인한 급격한 성능 붕괴 오차 +25.0% 급증
Lookback이 12h에서 48h로 늘어남에 따라 BPTT 역전파 체인룰의 거듭제곱에 의해 그래디언트가 0으로 수렴했습니다. 과거 24시간 이전의 정보를 전혀 학습하지 못하고 파라미터 업데이트가 정체되어 오차가 0.4290에서 0.5361로 25% 폭증했습니다.
∂L / ∂h_1 = (∂L / ∂h_{48}) · ∏_{t=2}^{48} [diag(1 - h_t²) W_hh^T] ≈ 0 (수학적 증명)
2. LSTM: Cell State 가산적 고속도로의 견고한 방어 0.44~0.45대 유지
선형 덧셈 구조인 C_t = f_t C_{t-1} + i_t C̃_t 덕분에 망각 게이트 f_t ≈ 1.0 유지 시 그래디언트가 48스텝 이전까지 감쇠 없이 직통 전달되었습니다. 시퀀스 길이가 4배로 늘어나도 0.44대의 안정적 오차를 흔들림 없이 방어했습니다.
3. GRU: 48시간 일주기(Diurnal) 패턴 최적 압축 MSE 0.4084 🏆
48시간(이틀치)은 변압기의 24시간 일주기 부하 패턴 2주기를 완전 관측할 수 있는 최적 시계입니다. GRU의 업데이트 게이트(z_t)가 주야간 부하 변동을 가장 효과적으로 압축하여, 전체 9개 실험 조건 중 가장 우수한 MSE 0.4084, MAE 0.4305를 기록했습니다.
