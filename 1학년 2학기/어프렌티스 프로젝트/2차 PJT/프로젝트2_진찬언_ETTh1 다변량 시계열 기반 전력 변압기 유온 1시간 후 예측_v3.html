Baseline Selection 02 / 05
동일 조건의 3개 기본 모델 비교 및 베이스라인 선정 Agenda 2
동일한 학습 환경(Train 60%)에서 RNN, LSTM, GRU를 공정 평가하여 최적 베이스라인 모델 x 선정

1. Vanilla RNN (단순 순환 신경망)
단일 tanh 순환 전이 구조. 타임스텝이 길어질수록 그래디언트 소실(Vanishing Gradient)로 인해 장기 의존성 학습 한계 발생
2. LSTM (Long Short-Term Memory)
Cell State($c_t$)와 3개 게이트(Forget $f_t$, Input $i_t$, Output $o_t$) 분리를 통해 장기 시계열 정보를 손실 없이 보존
3. GRU (Gated Recurrent Unit)
Reset($r_t$), Update($z_t$) 2개 게이트로 Cell과 Hidden을 통합하여 계산 속도 향상 및 파라미터 경량화

Model Upgrade Architecture 03 / 05
모델 x(기본 LSTM)에서 모델 y(개선 LSTM)로의 성능 개선 Agenda 3
선택된 LSTM 기반 3대 구조 개선: 은닉 차원 확장 + GELU 비선형 Head + Residual Delta 잔차 예측
아키텍처 대조 (기본 모델 x vs 개선 모델 y)
[모델 x] 기본 LSTM 구조 Baseline
  • 기본 2계층 LSTM 순환 구조 (Hidden dimension: 64)
  • 단일 선형 예측 Head (Linear(64, 1))
  • 직접 절대 유온(OT) 예측 방식 (y_pred = Head(h_t))
[모델 y] 고도화 개선 LSTM 구조 Proposed Upgrade
  • 은닉 차원 2배 확대 (Hidden: 128) + Layer Normalization 적용
  • 심층 비선형 예측 Head (Linear(128, 64) → LayerNorm → GELU → Dropout(0.15) → Linear(64, 1))
  • 물리적 관성 반영 잔차 변화량 예측 (y_pred = last_OT + Δy)
모델 y 수식: ŷt = yt-1 + MLPGELU(LayerNorm(ht))
3대 개선 방법 및 공학적 기대효과
1. 은닉 차원 확대 (64 → 128) 및 LayerNorm 도입
[표현력 증대] 7개 다변량 전력 부하와 유온 간의 복잡한 열역학적 비선형 결합 관계를 충분히 모델링할 수 있는 파라미터 용량 확보 및 내부 공변량 변화 안정화
2. GELU 활성화 기반 심층 비선형 예측 Head 구축
[비선형 관계 학습 강화] 단순 1단 선형 사상의 표현 한계를 극복하고, 매끄러운 곡률을 제공하는 GELU와 Dropout(0.15)을 결합하여 복잡한 비선형 패턴을 일반화 손실 없이 추론
3. Residual Delta Prediction (이전 OT + 변화량 예측)
[시계열 변화량 예측 안정화] 변압기 절연유는 열용량에 의해 급격한 온도 도약이 불가능한 '물리적 관성'을 가짐. 절대값을 통째로 추정하는 대신 직전 유온(yt-1)에 온도 변화분(Δy)을 더하는 스킵 연결로 장기 드리프트 방지 및 변곡점 추종력 극대화

실측 데이터를 통한 3대 핵심 공학적 인과관계 규명
인과규명 1: Residual Delta의 압도적 오차 억제력 입증
잔차 변화량 예측 모듈을 제거하고 직접 예측(Direct Prediction)으로 전환할 경우, Test MSE가 0.4002에서 0.5362로 무려 +34.0% 폭증함. 이는 변압기 유온의 물리적 관성을 반영한 스킵 연결이 예측 안정성의 핵심 열쇠임을 정량적으로 입증함.
인과규명 2: 은닉 차원 확장(64→128)의 표현력 증대 효과
기본 모델 x(Hidden 64, MSE 0.4408) 대비 개선 모델 y는 은닉 차원을 128로 확장하고 LayerNorm을 적용하여 다변량 7개 변수의 상호작용을 포착하는 기저 표현력을 비약적으로 끌어올림.
인과규명 3: 정규화 비선형 Head의 일반화 안정성
LayerNorm과 Dropout(0.15)이 결합된 GELU Head는 복잡한 다변량 비선형 특징을 시계열 이상치 노이즈에 과적합되지 않도록 완충하며, Test 데이터셋 전체에 걸쳐 견고한 일반화 성능을 달성함.
