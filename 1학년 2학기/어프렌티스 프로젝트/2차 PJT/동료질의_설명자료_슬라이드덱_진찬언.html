💡 Test 성능이 더 우수했던 3대 복합 요인
1. 데이터 자체의 분산(Variance) 38.2% 감소

회귀 모델에서 오차 제곱합은 기저 데이터의 분산에 지배받습니다. Test 구간의 널뛰기 폭이 훨씬 작았기 때문에 수치적 MSE가 낮게 도출되었습니다.

2. Train 세트의 봄철 기온 학습 경험 일치

14개월간의 학습 데이터에 2017년 봄철 기온 상승 패턴이 온전히 포함되어 있어, 같은 봄철 주기인 2018년 Test 데이터에 모델이 매우 쉽게 적응했습니다.

3. Test 시 Dropout 비활성화(앙상블 효과)

학습 시에는 무작위로 노드를 끄는 Dropout(0.1)이 켜지지만, Test 평가 시에는 전체 파라미터가 100% 앙상블로 가동되어 성능이 극대화됩니다.

2. 모델 간 '동일 학습 예산(Fair Budget)' 보장

QUESTION 03. TRACKING DYNAMICS
'지연 없이 추종한다'의 공학적 의미 & Residual Delta 구조
1시간 전 값을 복사해 늦게 따라가는 위상 지연을 잔차 변화량 예측으로 완벽 극복
04 / 05
⚠️ 시계열 회귀의 고질병: 위상 지연(Phase Lag)
직접 예측의 함정: '1스텝 전 값 복사기'로 전락
절대값을 직접 맞추려다 보면 손실을 줄이기 위해 '직전 1시간 전 값을 그대로 출력'하는 Naive 복사기 편향에 빠지기 쉬움

• 현상: 유온이 급격히 상승하거나 꺾이는 피크(변곡점)에서 예측선이 실제선보다 1시간씩 오른쪽으로 밀려서 나타나는 위상 지연 발생.
• '지연 없이 추종'의 의미: 제안한 모델 y는 이 1시간 밀림 없이 실제값의 피크 발생 시점과 정확히 일치하여 실시간 동시 추종함을 의미함.

🛡️ Residual Delta 해결 원리 및 실증 증거
수식: ŷ_t = y_{t-1} + Δy (물리적 관성 반영)
변압기 오일은 열용량이 커서 급변 불가 → 직전값(y_{t-1})에 1시간 동안 변할 차이(Δy)만 더하도록 앵커링하여 지연 원천 차단
정량 실증: Ablation Study 오차 +34.0% 폭증!
4페이지 소거 실험에서 Residual Delta를 빼자마자 위상 지연 때문에 Test MSE가 0.4002에서 0.5362로 폭등함 (지연 억제 기여도 완벽 입증)
