# [어프렌티스 프로젝트 1] 제조 설비 고장 예측 머신러닝 5단계 실증 보고서 및 발표 자료


## 3. 슬라이드별 발표 대본 (자연스러운 3분 50초 구성 / 슬라이드 노트 동일 탑재)

> **💡 대본 스타일 (AI 클리셰 완벽 배제)**: 현업 대학원생의 차분하고 단단한 공학적 어조로 작성되었습니다. 슬라이드당 35~45초 배분으로 총 3분 50초 내외로 끝나 질의응답 시간을 충분히 확보할 수 있습니다.

### [1번 슬라이드] 표지 (약 30초)
> "안녕하세요. 어프렌티스 프로젝트 발표를 맡은 진찬언입니다.  
> 저는 이번 과제에서 실제 공작기계 센서 데이터를 바탕으로, 수업 시간에 배운 머신러닝 5대 핵심 절차를 직접 구현하고 검증했습니다.  
> 특히 검증 데이터 분리의 필요성, 스케일링에서의 데이터 누수 방지, 그리고 하이퍼파라미터 튜닝 효과를 중심으로 말씀드리겠습니다."

### [2번 슬라이드] 1단계. 데이터와 문제 정의 (약 40초)
> "첫 번째로 데이터와 예측 문제입니다.  
> 사용한 데이터는 케글 공개 데이터셋으로 공작기계 센서 로그 1만 건이며, 가공 중 고장 여부를 사전에 감지하는 이진 분류 과제입니다.  
> 왼쪽 차트를 보시면 고장률이 3.4%에 불과한 희소 불균형 데이터이고, 회전수와 토크, 온도 등 센서별 수치 범위 편차가 매우 큽니다.  
> 이러한 한계를 극복하기 위해 설비 방열과 동력, 공구 피로를 반영한 물리 파생 특성 3가지를 추가하여 고장 판별력을 확보했습니다."

### [3번 슬라이드] 2단계. 데이터 분할 및 검증셋 비교 (약 45초)
> "두 번째로 데이터 분할과 검증셋의 필요성입니다.  
> 왼쪽 그래프를 보시면 검증셋 없이 학습과 시험을 8대 2로 나누면, 시험 데이터를 보면서 모델을 고치게 되어 시험 점수는 높게 나와도 실전에서 성능이 급락합니다.  
> 반면 학습 60, 검증 20, 시험 20으로 3단계 층화 분할을 하면, 검증셋으로만 파라미터를 튜닝하고 시험셋은 온전히 보존할 수 있어 정직한 실전 성능을 측정할 수 있었습니다."

### [4번 슬라이드] 4단계. 스케일링과 데이터 누수 방지 (약 45초)
> "네 번째로 데이터 스케일링과 누수 방지입니다.  
> 왼쪽 차트처럼 모터 기동 시 발생하는 토크 이상치 때문에, MinMax나 Standard는 데이터 왜곡이 심합니다. 따라서 중앙값과 사분위수를 쓰는 로버스트 스케일러를 채택했습니다.  
> 또한 스케일러 기준값은 오직 학습 데이터 60%에서만 계산하고, 검증과 시험 세트에는 변환만 적용하여 미래 정보가 학습에 유출되는 데이터 누수를 완전히 막았습니다."

### [5번 슬라이드] 3단계. 하이퍼파라미터 튜닝 (약 40초)
> "세 번째로 하이퍼파라미터 튜닝입니다.  
> 랜덤 포레스트 모델에서 트리 깊이와 분류 임계값을 검증셋 기준으로 튜닝했습니다.  
> 깊이 제한이 없으면 학습 데이터는 100% 다 맞히지만 정작 희소 고장 재현율은 50%에 그칩니다.  
> 왼쪽 차트처럼 트리 깊이를 10으로 규제해 과적합을 잡고, 결정 임계값을 0.35로 조정한 결과, 고장 재현율이 50%에서 86.8%로 36.8%p 대폭 향상되었습니다."

### [6번 슬라이드] 5단계. 최종 평가 및 결론 (약 40초)
> "마지막 5단계 최종 평가와 결론입니다.  
> 모든 튜닝을 마친 뒤, 밀봉해 두었던 2천 건의 시험 데이터를 단 한 번 평가했습니다.  
> 왼쪽 혼동 행렬을 보시면 실제 고장 68건 중 59건을 성공적으로 검출하여 재현율 86.8%, F1 점수 0.868, ROC-AUC 0.986을 기록했습니다.  
> 이로써 검증셋 분리, 스케일링 누수 방지, 파라미터 튜닝이라는 머신러닝 5대 핵심 절차를 성공적으로 완수했습니다. 경청해 주셔서 감사합니다."

## 4. 질의응답(Q&A) 완벽 대비 전략

### 4.1 나에게 들어올 예상 질문 & 완벽 모범 답변

**Q1. "고장률이 3.4%밖에 안 되는데 SMOTE 같은 오버샘플링을 쓰지 않고 임계값 조정(0.35)을 선택한 이유는 무엇인가요?"**
> **모범 답변**:  
> "좋은 질문이십니다. 공작기계 센서 데이터는 물리 법칙을 따르기 때문에, 임의로 가상 데이터를 합성하는 SMOTE를 적용하면 실제 물리적으로 발생할 수 없는 센서 조합(예: 저토크 초고온 현상)이 만들어져 노이즈가 유입될 위험이 있습니다.  
> 따라서 원천 데이터의 물리적 연속성을 훼손하지 않으면서, 현장 관점에서 치명적인 고장 미감지를 방지하기 위해 분류 임계값을 검증 세트 기준으로 0.35로 낮춰 재현율을 확보했습니다."

**Q2. "랜덤 포레스트 트리 깊이를 10으로 제한한 정량적 근거는 무엇인가요?"**
> **모범 답변**:  
> "검증 데이터의 F1 점수와 과적합 격차를 모니터링하며 결정했습니다. 트리 깊이 제한이 없을 때는 학습 정확도 100%, 검증 F1은 0.86 수준이었으나 학습과 검증의 성능 격차가 38%에 달해 과적합이 심했습니다.  
> 깊이를 4, 6, 8, 10으로 탐색한 결과, 깊이 10에서 학습과 검증 세트 간 격차가 9.3%로 안정화되면서도 복잡한 물리 결합 특성을 충분히 학습할 수 있는 최적의 균형점으로 확인되었습니다."

**Q3. "스케일러로 StandardScaler 대신 RobustScaler를 선정한 물리적 이유는 무엇인가요?"**
> **모범 답변**:  
> "공작기계 모터는 급기동이나 절삭 진입 시 일시적인 토크 스파이크가 발생하여 극단적인 이상치(최대 76.6Nm)를 형성합니다.  
> StandardScaler는 평균과 표준편차를 쓰기 때문에 이러한 스파이크 이상치 하나에 전체 스케일 기준이 왜곡됩니다. 반면 RobustScaler는 중앙값과 IQR(사분위범위)을 기준으로 스케일링하므로, 이상치에 영향을 받지 않고 정상 가공 영역의 50% 신호 해상도를 온전히 보존할 수 있어 최종 선정했습니다."

### 4.2 9월 16일 동료 리뷰어 등록용 핵심 질문 3선 (자연스러운 한국어 구어체)

> 채민선 교수님 지침: *"최소 3개 이상의 질문 의무 등록"*, *"질문 수준에 따라 본인이 돋보일 수 있다"*  
> 아래 3개 질문은 머신러닝의 가장 핵심적인 취약점을 찌르는 고수준 질문입니다.

1. **데이터 누수 질문 (가장 결정적인 변별력 질문)**:  
   *"발표 잘 들었습니다. 데이터 전처리하실 때 스케일러를 전체 데이터에 먼저 적용하고 나누셨는지, 아니면 학습 데이터로만 기준값을 산출(fit)하고 검증과 시험 데이터에는 변환(transform)만 적용하셨는지 궁금합니다."*

2. **검증 데이터 유무 비교 질문 (2단계 미션 핵심)**:  
   *"2단계 미션에서 검증 데이터가 없을 때와 있을 때의 차이를 분석하셨는데, 검증 데이터가 없을 때는 모델 하이퍼파라미터를 어떤 기준으로 조정하셨고, 그로 인해 시험 데이터에 어떤 오버피팅 현상이 나타났는지 궁금합니다."*

3. **불균형 데이터 분할 질문**:  
   *"제조 데이터 특성상 불량 데이터가 매우 희소했을 텐데, 데이터를 나누실 때 일반 무작위 분할을 하셨는지, 아니면 불량 비율을 세 세트에 균등하게 유지해주는 층화 분할(Stratified Split)을 적용하셨는지 궁금합니다."*
